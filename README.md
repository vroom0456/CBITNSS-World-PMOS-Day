# World PMOS Day 2026 - Awareness Campaign

A premium, highly-responsive web platform built for the **CBIT NSS Core Committee 2026–2027** to raise awareness about Polycystic Metabolic Ovary Syndrome (PMOS) — formerly known as PCOS.

## 🎯 Campaign Mission
To destigmatize PMOS, provide evidence-based medical information, and offer confidential support resources to students on the CBIT campus and beyond. The platform emphasizes the shift from "PCOS" to "PMOS" to highlight the systemic metabolic and endocrine nature of the condition, rather than focusing solely on ovarian cysts.

## ✨ Features
- **Modern Next.js Architecture**: Fast, SEO-optimized, and built on React Server Components with Next.js 16 (Turbopack).
- **Responsive Bootstrap Layout**: 100% mobile-first design, specifically optimized and audited for small screens (320px+).
- **Evidence-Based Content**: Features verified medical facts, symptom checklists, and science-backed lifestyle interventions.
- **Confidential Support Integration**: Direct access to national helplines and CBIT campus support (Women's Administrator).
- **Interactive Elements**: Dynamic CSS animations, a comprehensive self-assessment UI, and smooth page transitions.

## 🚀 Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠 Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Vanilla CSS + Bootstrap Utility Classes (Dynamic `clamp()` fluid typography & spacing)
- **Deployment**: Vercel Ready
